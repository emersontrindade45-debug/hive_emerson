# Modelo de Negócios — os 3 pilares

**Squad:** Intelligence (Emerson) · **Interface:** Finance (Lorenzo) para margem real; Commercial (Tatiane) para precificação de venda

## Regra de ativação

Esta skill é **obrigatória** antes de opinar se uma oportunidade vale a pena. O Emerson declarou este framework como **lente de avaliação de toda oportunidade** — responder sem aplicá-lo contraria uma decisão registrada dele.

## Passo 1 — Ler a fonte

**`squads/intelligence/foundation/business-opportunities.md`** § "Material estratégico (framework do Emerson)".

## Passo 2 — Aplicar os 3 pilares

Um negócio **sem os três** não é considerado bom modelo:

| Pilar | Pergunta objetiva | Critério |
|---|---|---|
| **Recorrência** | O cliente volta a comprar? Existe esteira (grátis → livro → curso → mentoria)? | Sem recorrência, não interessa. Esteira boa = CAC menor, LTV maior |
| **Escala** | O mercado endereçável é grande? Existe canal de expansão que não dependa do dono? | Começar pequeno é ok; **planejar para ficar pequeno é o problema** |
| **Margem** | A margem líquida (EBITDA) bate **≥30%**? | Abaixo disso, o autor do curso não analisa |

## Passo 3 — Distinguir tipo × modelo

**Erro mais comum:** confundir *tipo de negócio* (o setor) com *modelo* (a arquitetura). O mesmo tipo comporta infinitos modelos — supermercado pode ser tradicional, digital, por assinatura ou vending em condomínio.

Sempre perguntar: **isso é tipo de negócio ou é modelo?** Dá para desenhar arquitetura diferente para o mesmo tipo que já existe?

## Passo 4 — Precificar pelo ROI do cliente

**Nunca pela média dos concorrentes.** "Caro não é valor absoluto — caro é o que não gera retorno."

As 3 formas de aumentar margem: (1) preço pelo ROI do cliente; (2) planejamento tributário — dentro da lei, com tributarista; (3) branding.

⚠️ Precificar exige **prova** (cases, depoimentos, resultados). Sem entrega comprovada, qualquer preço é caro.

## Passo 5 — Procurar "piloto automático"

Copiar o concorrente sem repensar a arquitetura é **red flag, não vantagem**. O caso Wise Up (24 → ~400 escolas, vendida por US$ 500M, com **95% do valor na editora** e só 5% na rede de escolas) mostra que a troca de modelo — de dono de operação para dono de marca + propriedade intelectual — foi o que destravou escala.
